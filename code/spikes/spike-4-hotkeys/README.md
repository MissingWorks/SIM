# Spike-4 — الاختصارات العامة (المرحلة 0)

**الغرض:** حسم U06 + D11 — تسجيل Win+Alt+V و Win+Alt+1..9، كشف التعارضات، وإعادة التسجيل بعد «تغيير الإعدادات».
**الحالة:** ✅ مكتمل 2026-10-18 — النتائج في `../../../plan/plans/phase0-results.md` (قسم Spike-4).

## ملخص النتائج

- **Win+Alt+V**: سُجل وأُطلق بنجاح ✅ (الاختصار المعتمد لفتح اللوحة).
- **Win+Alt+1..9**: كلها محجوزة من برنامج على الجهاز (1409) — لا تصلح افتراضيًا.
- **probe:** كل تركيبات Win+رقم محجوزة (Win+Shift/Ctrl+Win أيضًا)؛ البدائل الحرة: **Ctrl+Alt+1..9**، Ctrl+Shift+1..9، Win+Alt+Shift+1..9 → **D11 منقح: Slots = Ctrl+Alt+1..9**.
- إعادة التسجيل بعد تغيير الإعدادات ✅ (Unregister → Register).

## التشغيل

1. `cargo build --release`
2. `run-hotkeys.cmd` — نافذة سوداء: مرحلة 1 (45 ثانية، اضغط Win+Alt+V ثم 1..9) ثم دورة إعادة تسجيل + مرحلة 2 (20 ثانية).
3. `target\release\spike4-hotkeys.exe probe` — فحص بدائل التركيبات (تسجيل فقط، بلا ضغط).
4. النتائج في `spike4-log.txt` و`spike4-probe.txt`.

> مجلد تجربة مؤقت — لا يدخل الإصدار (يُؤرشف/يُحذف عند إغلاق المرحلة 0).
