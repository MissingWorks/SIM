# Spike-7 — صمود اللصق (المرحلة 0)

**الغرض:** قياس سلسلة اللصق التلقائي (D13 + D20): استعادة المقدمة المباشرة مقابل خدعة ALT، نجاح Ctrl+V داخل التطبيقات، وضبط `paste_restore_delay_ms`.
**الحالة:** ✅ مكتمل 2026-10-18 — النتائج الكاملة في `../../../plan/plans/phase0-results.md` (قسم Spike-7)، والدليل الخام في `spike7-log.txt`.

## ملخص النتائج

- اللصق المباشر: **5/5 نجاح** (Notepad/Chrome/Discord/OpenCode) — خدعة ALT **لم تُستخدم**.
- `paste_restore_delay_ms = 60` معتمدة (إرسال Ctrl+V خلال 92–100ms من الضغط).
- **درس:** فتح اللوحة من أيقونة الصينية يلتقط نوافذ شريط المهام (explorer) كهدف — الإصلاح: استبعاد أصناف نوافذ القشرة + الفتح باختصار عام (Win+Alt+V).
- نافذة admin لم تُقس — أُحيلت إلى U08 (المرحلة 3/4).

## التشغيل (لإعادة التجربة)

1. `cargo build --release`
2. `run-spike7.cmd` — تظهر اللوحة وسط الشاشة + أيقونة صينية + اختصار Win+Alt+V.
3. ركّز نافذة الهدف → Win+Alt+V → **Paste (Enter)**.
4. السجل الكامل في `spike7-log.txt` (كل خطوة بزمنها).

## بنية الأداة

- متتبع هدف كل 200ms (hwnd/pid/اسم العملية) مع استبعاد نوافذ القشرة.
- كتابة الحافظة عبر windows-rs الخام + علامة `SIMSpike7Marker` (نمط D25).
- اختصار عام Win+Alt+V عبر RegisterHotKey + حلقة رسائل خيط مستقلة (إشارة مبكرة لـ Spike-4).
- `spike7_paste(delay_ms, use_alt)`: التدفق كاملًا مع تقرير خطوات؛ `spike7_copy_only`: نسخ + رسالة fallback.

> مجلد تجربة مؤقت — لا يدخل الإصدار (يُؤرشف/يُحذف عند إغلاق المرحلة 0).
