# code — الكود المصدري

> **حاليًا فارغ.** يُبنى المحتوى الفعلي في المرحلة 1 (Cargo Workspace).

## البنية المخططة (Plan A)

```
code\
├── Cargo.toml                  ← تعریف workspace
├── crates\
│   ├── winsuite-core\          ← المحرك: التقاط، تخزين، إعدادات، أحداث (بلا واجهة)
│   ├── winsuite-desktop\       ← تطبيق Tauri: Tray + اللوحة + الإعدادات
│   └── winsuite-cli\           ← أداة تطوير/اختبار المحرك بدون واجهة
└── ui\                         ← ملفات الواجهة (HTML/CSS/JS) الخاصة بـ winsuite-desktop
```

## قواعد

- ممنوع كود منطق داخل الواجهة (JS) — الواجهة تعرض وتستدعي أوامر Core فقط.
- كل منطق قابل للاختبار يعيش في `winsuite-core`.
- لا تبعية جديدة بدون تسجيلها في `../plan/LIBRARIES.md`.

## أوامر مؤجلة (تُضاف عند وجود الكود)

| الأمر | الغرض |
|---|---|
| `cargo build` | بناء التطوير |
| `cargo test` | الاختبارات |
| `cargo clippy -- -D warnings` | فحص الجودة |
| `cargo tauri dev` (من مجلد التطبيق) | تشغيل مع إعادة تحميل الواجهة |
| `cargo tauri build` | إنتاج النسخة النهائية |
